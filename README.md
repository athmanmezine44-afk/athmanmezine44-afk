## 👨‍💻 About Me

I'm a Master's student in Computer Engineering (M2I) at the Faculty of Sciences of Oujda (Université Mohammed Premier), with a Data Science background. I build applications end to end, from the REST API and the database to the interface, and I like to ship them with containers and CI/CD.

My work sits between **Full Stack development**, **Data & AI** and **Cloud & DevOps**: Spring Boot and Angular applications, Big Data pipelines with PySpark, computer vision with YOLOv8, and Kubernetes deployments.
